# 4.4.6

## 新增：Windows x64 交叉编译发布支持

- 平台资源拆分：macOS 与 Windows 各自只打包对应平台的 opencode 二进制
  （`tauri.macos.conf.json` / `tauri.windows.conf.json`），不再互相带冗余产物。
- 新增 `scripts/build-windows-release.sh`（Apple Silicon 上 xwin 交叉编译
  Windows x64 NSIS 包，含 makensis / LLVM 前缀修复）。
- 交叉编译时第一方插件（mobile-codex / desktop-sync）无 Windows 产物则跳过
  校验而非构建失败；Windows 包默认不打包这两个插件目录，避免混入 macOS 二进制。

## 修复：CLI 安装检测在 GUI 启动环境下误判

- GUI 从 Finder / Dock 启动时 PATH 往往只有系统目录，不含
  `~/.npm-global/bin`、`~/.n/bin` 等用户安装目录；spawn CLI 时补充完整
  PATH，避免 `env node` 类脚本（如 dsh）因找不到 node 而被误判为未安装。

## 个人中心与状态栏

- 匿名使用统计默认折叠，界面更简洁。
- 授权范围与已授权应用并排一行展示。
- 修复 CLI 角标横线偏右、服务概览 Dock 角标内图案水平居中问题。

## DEXAI Debug 支持端

- 支持端 UI 精简与文案统一，优化视觉语言。
- 终端改为弹窗展示，输入框占位统一 3 空格。
- 修复终端字体与编码显示、删除键光标乱走的问题。
