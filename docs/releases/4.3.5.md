## 4.3.5

### 新增

- **DEXAI Debug 远程调试插件**（第一方插件）：
  - 独立 netd（Tailscale）实例，与 Mobile Codex 节点隔离；短码授权（10 位 /
    5 分钟 / timing-safe 校验）、作用域命令执行、全程审计（日志自动轮转）、
    敏感字段脱敏；
  - 插件详情页内嵌「远程调试」面板：本机（启用开关 / 目标地址 + 短码 /
    复制）+ 支持端（粘贴连接 / 诊断摘要 / 命令执行 / 断开）；
  - 自动注册：主账号授权后向 control-plane 领取 headscale 一次性 auth key，
    免手动配置；复制走系统剪贴板（Rust arboard），粘贴支持地址 + 短码自动解析。
- 客户端 Dock 右键新增「清理配置文件」：按客户端专属路径精确清理，
  确认对话框支持勾选是否同时移除 DEX AI 账号。

### 修复

- 插件市场 Skill 专区首次进入不再"正在加载"（补 `_wbVisibleCount` 声明、
  专区加载入口与 `_wbSection` 同步）。
- DEX 插件专区切换不再重复拉取后端；市场列表跳过 `source_hash` 计算，
  首次加载从数秒降至毫秒级；已安装卡片统一网格样式、隐藏分类 tab、
  单条不拉伸、圆角统一。
- macOS 上 Windows 适配提交的编译错误（`dex_clients.rs` / `lib.rs` 类型注解）。
- debug 构建默认与安装版共存（单实例放行），本机验证不再冲突。

### 其它

- control-plane 新增 `POST /v1/debug/network-credentials`（DEXAI Debug
  签发 headscale auth key）与账号云同步（vault / prefs）能力。
- 发布脚本 `build-gui-release.sh` 支持 DEXAI Debug 插件哈希校验。
