## 4.0.5

- 兼容 Codex 桌面新版（ChatGPT.app）渲染进程，解决 Statsig/模型下拉在 4.0.1 上失效的问题。
- 修复 Codex 模型选择器账号/模型显示格式：API 模式显示"账号 / 模型"，智能路由/中转模式保持原 deecodex 行为。
- 智能路由和中转模式同步修复 native 账号判断，允许 probe cache 里的 gpt-5.6+ 新模型进入目录。
- router 端点选择增加 native executor 的 known_models 白名单 + account.model_map 优先解析，避免选中不支持所请求模型的端点；无匹配 endpoint 时区分 no_supported_endpoint 与 model_unsupported 两种失败原因。
- 端点 image_generation 能力增加运行时禁用缓存：上游首次返回 403 + image_generation permission_error 时自动 strip 可选生图工具重试，成功后该端点标记为 runtime disabled，后续请求直接走 strip 路径，不再重复命中上游错误。
- Codex 注入脚本 `账号 / 模型` 格式按 mode 走持久化 config.json 判定，5 秒刷新一次 mode 缓存。
