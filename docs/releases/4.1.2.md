## 4.1.2

### 新增

- 插件详情页与个人中心新增「启动 ChatGPT（桥接模式）」按钮：仅由用户在 GUI
  显式触发时才以透明 Shim 模式拉起 ChatGPT 桌面版，手机桥接环境由 Companion
  自动配置。
- Mobile Codex 插件升级到 0.1.23：Companion 自动启动 / start / restart 不再
  强制重启或拉起 ChatGPT 进程；`service.status` 返回 `chatgptBridge`
  （`shim` / `official_mode` / `not_running`），GUI 据此显示引导。

### 其它

- 内置第一方插件哈希更新（`DEECODEX_MOBILE_CODEX_PLUGIN_SHA256` 对应 0.1.23）。
