- 修复同一会话从 GPT-5.6 Sol 切换到 DeepSeek V4 Flash 后再切回 GPT 时，历史明文 `reasoning.content` 导致上游返回 `array too long` 的问题。

- 第一方插件更新改为仅在用户明确操作时执行，并在下载校验通过后信任已解包的受控插件源。
- Windows 发布构建会清理旧 NSIS bundle 暂存文件，避免内置插件哈希与实际资源不一致。
