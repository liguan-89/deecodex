## 4.1.0

### 个人中心（DEX AI 主账号）

- 主账号注册接入：登录页新增注册模式（邀请码 + 邮箱 + 密码，密码至少 12 位），
  提交后自动登录；邀请码处补充「联系作者获取」提示。
- 授权中心：待授权插件 / 已授权应用 / 撤销授权 / 最近授权记录，统一在个人中心管理。
- 管理界面与登录页对齐同一全屏约束线，内部简洁分组，去除表单感。
- 插件市场授权门禁绑定 DEX AI 主账号（退出个人中心后立即锁定）。

### 登录页视觉

- 登录 / 注册按钮改为黑白风格（暗色主按钮白底黑字，亮色黑底白字）。
- 亮色主题下动画区改为界面白色渐变，暗色保留灰色渐变。
- 注册表单输入框恢复角色动画（打字 / 密码聚焦 / 长度反应）。

### 联系作者

- 个人中心登录页与服务概览均支持「联系作者」二维码弹窗。
- 弹窗统一展示作者二维码、支付宝收款码、微信收款码三张（白底统一包装）。

### 其它

- Codex 内部辅助请求识别增强（memory / 子任务多标记识别）。
- 客户端右键菜单新增「更新」（CLI 终端更新，桌面版检测版本并打开官方页）。
- 状态页客户端 Dock 支持卸载与快速配置。
- 发行包捆绑 opencode 引擎二进制并修复 resolve_binary 查找。
- DEX 助手 L3 工具权限覆盖防御校验。
