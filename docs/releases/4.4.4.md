# 4.4.4

## DEXAI Debug 远程支持升级（配合插件 0.1.5）

- **SSH/TCP 隧道**：支持端连接目标后，可把目标本地 22 等端口经 tailnet 通道
  透传到本机，直接用 `ssh` / `scp` 操作目标机（应用层透传，不暴露公网端口）。
- **GUI 内置交互式终端**：引入 xterm.js，支持端连接目标后一键打开终端，
  不依赖目标机 sshd（覆盖客户机场景）；macOS/Linux 为完整 PTY，Windows 为
  交互 cmd。
- DEXAI Debug 插件自动启用时自动刷新一次性 authkey，避免启动即过期注册失败；
  插件 netd 直连 headscale 超时自动回退走代理，提升跨机器注册稳定性。
- headscale 侧：清理 20+ 历史测试僵尸节点；新注册节点 180 天不活跃自动过期。
