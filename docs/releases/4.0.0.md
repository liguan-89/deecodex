## 4.0.0

- 新增 Codex Desktop 中转渠道模式，支持独立保存 DEX AI 中转 URL/API Key，并通过 `/codex-relay/v1` 路由保持 Codex 内置 GPT 模型标识。
- 账号管理新增中转渠道池，可添加、粘贴、测试、切换和删除中转渠道，敏感 Key 在界面和返回值中脱敏。
- 中转模式接入故障统计、冷却和成功/失败记录，为多渠道自动切换和诊断面板提供运行状态依据。
- 快捷配置新增中转模式默认推荐，优化表单默认值、布局和 Codex 模型直选体验。
- 优化账号页、线程聚合界面和中转诊断/使用统计展示，减少重复项目和状态不一致带来的误判。
