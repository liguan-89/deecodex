## 4.3.7

### 修复

- DEXAI Debug 在代理（clash 等）环境下无法生成目标地址：
  Tailscale（Go）默认不读 macOS 系统代理，DNS 被 clash fake-ip 劫持时
  netd 直连 headscale 失败（`tsnet.Up: context deadline exceeded`）。
  现在 netd 启动时自动读取系统 HTTP 代理，或探测常见本地代理端口
  （7890/7897 等，能连通 headscale 即采用），注入 `HTTPS_PROXY`/`HTTP_PROXY`
  （`NO_PROXY` 排除 tailnet CGNAT 网段），控制连接走代理到公网 headscale。
