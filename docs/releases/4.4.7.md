# 4.4.7

## Windows 兼容性全面加固（本轮重点）

覆盖 11 类问题，双端（macOS / Windows）均适用，Windows 端重点修复：

- **终端交互**：内置终端连接 Windows 时回车不再无效（cmd 管道 `\r`→`\r\n` 规范化），DEXAI Debug 远程终端可正常输入。
- **不再弹黑框**：全部子进程（powershell / cmd / tasklist / curl / opencode / netd 等）统一 `CREATE_NO_WINDOW` 隐藏控制台窗口。
- **路径兼容**：修复 PATH 分隔符（`;`）、Codex 会话/临时工作区路径识别（归一化反斜杠）、HOME/USERPROFILE 差异。
- **换行符/BOM**：写回 Codex 文件保留 CRLF、兼容 UTF-8 BOM/UTF-16 配置、插件包哈希行尾说明。
- **字符编码**：PowerShell 输出强制 UTF-8、中文系统 GBK 输出正确解码、端口占用判定不再依赖本地化文本。
- **命令/进程**：Windows 补齐 `taskkill/netstat/tasklist/Get-CimInstance/Get-Content` 等价实现；后台 daemon 不再弹控制台。
- **动态库/WebView2**：安装包改为离线安装模式（内嵌 WebView2 Runtime），无网络环境也能安装。
- **文件锁**：账号锁文件在 Windows 用 `LockFileEx` 真正互斥；原子写失败有回退。
- **配置目录**：opencode 原生配置适配 Windows `%APPDATA%`，账号快速配置在 Windows 生效。
- **GUI/线程**：启动时插件初始化改为后台执行、长阻塞命令 `spawn_blocking`，窗口不再卡白屏/无响应。

## 其他
